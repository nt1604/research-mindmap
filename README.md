# Synapse Research - 思考整理・研究ノート (v3.1)

> **トップダウン（大きな問い・仮説）とボトムアップ（先行研究・実験データ）を有機的に統合する思考整理ツール**

研究や論文執筆におけるアイデアの発想、先行研究の整理、実験データの検証、そして論理の構造化をスムーズに行うためのWebアプリケーションです。  
外部サーバー不要・完全無料で、ブラウザで開くだけですぐに利用できます。

---

## 🌟 主な進化・新機能（v3.1 最新版）

### 0. スマホ・iPad・Apple Pencil 完全対応 (v3.1 新機能)
- **指での直感的ナビゲーション**：
  - **1本指でスワイプ**：キャンバスの移動（パン）や、カードの自由なドラッグ移動が指先に吸い付くように動作。
  - **2本指でピンチ**：広げる・つまむ直感的な操作で、キャンバスをスムーズに拡大・縮小。
  - **誤スクロール防止**：操作中にブラウザ全体が引っ張られてリロード（再読み込み）される誤作動を完全に防止。
- **Apple Pencil（ペンシル）高精度操作＆パームリジェクション**：
  - ペン先による超精密なカード移動や、矢印（コネクタ）のピンポイント接続。
  - ペン使用時に手のひらが画面に触れても誤動作しない「パームリジェクション」を完備。
  - iPadOS標準の「スクリブル（手書き文字変換）」にも対応し、キーボード不要で手書き入力が可能。
- **マルチデバイス・レスポンシブデザイン**：
  - PCの大画面では洗練されたフルサイズツールバー。
  - スマートフォンやiPadの縦画面でもヘッダーやモーダルが自動最適化され、崩れず快適に操作可能。

### 1. グループ機能 ＆ 一括収納・展開（スマートボックス）
- **グループ枠の作成と自由な色選択**：
  - 「+ グループ」ボタンからカード群をまとめる枠を作成。
  - グループ名の変更や、グラデーションカラーパレットからの色変更が可能。
- **カードの所属切り替え（シンプルなカラードット）**：
  - 各カード下部にある色付きの「ドット（⚪ / 🔵 / 🟢 等）」をクリックするだけで、どのグループに属するか直感的に切り替え可能。グループがないときは表示されずカードを邪魔しません。
- **「📂 収納」と「📁 展開」**：
  - 「収納」ボタンを押すと、属するカードが箱の中に吸い込まれるように収納され、キャンバスが劇的にすっきりします。
  - 「展開」ボタンを押すと、元の位置・レイアウトへと瞬時に復元されます。
- **収納時のジャンル別カラー・バッジ**：
  - 箱の中に収納されたカードは、**「問い・仮説（青）」「知見・メモ（緑）」「検証・合流（橙）」「その他（桃）」**の淡い背景色とカラーバッジ付きタイトル帯で表示。何が収納されているか一目で把握できます。

### 2. 矢印の生え際固定＆滑らかな曲線追従（スマートコネクタ）
- カードをつなぐ際、**引っ張り始めた丸（上・下・左・右）と相手の丸がしっかりと固定**されます。
- カードの位置を上下左右に動かしても、矢印の生え際が勝手にジャンプせず、位置関係に応じて**自然で美しいベジェ曲線（S字・U字カーブ）**を描いて追従します。
- 線の種類（実線／破線／矢印の向き／色など）も自由にカスタマイズ可能です。

### 3. AI研究サポート（Gemini連携）＋ 独自の追加指示機能
- 論文PDF、テキスト要約、音声ボイスメモ（mp3/m4a等）を投入すると、AIが「問い・仮説」や「知見・データ」のカードへ自動分解します。
- **「AIへの追加指示・着眼点」入力欄**：
  - 「仮説検証の論理に注目して分解してほしい」
  - 「結論だけでなく実験手法のカードも作ってほしい」
  など、あなたの研究目的に合わせた特別な指示を添えてAIに解析させることができます。
- **カード事前確認モーダル**：AIが作成したカードをいきなりキャンバスに置くのではなく、事前に編集・取捨選択してから配置できます。

### 4. 4つの研究ジャンル（属性）に対応
思考の性質に合わせて4色のカラーとバッジでカードを分類できます：
- **問い・仮説**（Top-down / 青色）：研究の核となるリサーチクエスチョンや仮説
- **知見・メモ**（Bottom-up / 緑色）：先行研究の引用、サーベイメモ、観察結果
- **検証・合流**（Synthesis / 橙色）：実験結果、考察、仮説の支持・棄却の結論
- **その他・自由設定**（Custom / 桃色）：課題、TODO、アイデアなど自由に名前を設定可能

### 5. 画面サイズ・レスポンシブ最適化
- ノートPCやタブレット、スプリット画面でもヘッダーのボタンやタブがはみ出さないよう、自動調整と横スクロール対応を実装。

### 6. プロジェクト管理・セーブ機能＆バックアップ（自動救済機能付き）
- **プロジェクト別セーブ**：「卒論_テーマA」「先行研究サーベイ」など、名前をつけて複数保存・即座に切り替え可能。
- **2段階スマート削除（確実な削除）**：「削除」ボタンを押すと赤色の「本当に削除？」に変化し、もう一度押すだけで確実にローカル＆クラウドから完全消去可能。
- **自動データ救済・自己復元機能**：スマホや新しい端末で開いた際、個別プロジェクトキーが未生成の場合でも、端末内のメイン保管庫から自動でカード（11枚等）を検知して復元して開く安心設計。
- **JSON書き出し・読み込み（端末間データ移行）**：PCの「書き出し」で保存したファイルをスマホの「読み込み」で開くだけで、PCとスマホ間で完全なデータ移行が可能。
- **Google / Firebaseクラウド同期**：ログインすることで複数端末間でリアルタイムに最新のカードとプロジェクトを自動同期可能。

## 🔍 Google連携・Gemini・GitHubアップロードについて

### Q. GitHubに上げさえすればいいの？
**はい！このフォルダの内容をGitHubにプッシュするだけで、GitHub Pagesにより完全無料でどこからでも使えます。**

- **Gemini API（AI解析）**：
  - アプリ内の「AI支援」画面から、ご利用者様ご自身のGemini APIキーを入力して使う設計になっています。
  - APIキーは個人のブラウザ（LocalStorage）にのみ安全に保存されるため、**GitHubに公開リポジトリとしてアップロードしてもAPIキーが漏洩する危険はありません。**
- **Googleログイン / Firebase連携**：
  - 現在ローカル保存（ブラウザ保存）とJSON書き出しで完全動作しています。
  - Firebaseによるクラウド同期を行う場合は、Firebase Consoleでプロジェクトを作成し、発行された設定値（apiKey, projectId等）を `app.js` の `firebaseConfig` に反映することで有効化されます。

## 🚀 使い方

### PCでの利用（一番かんたん）
1. フォルダ内の `index.html` をダブルクリックしてブラウザ（Google Chrome, Edge等）で開きます。
2. これだけでインストール作業なしですぐに使えます！

### スマートフォンや外出先からの利用（完全無料）
1. GitHubのリポジトリに本フォルダのファイルをアップロードします。
2. リポジトリの **Settings ➡ Pages** を開き、「Branch: main / (root)」を選んで保存すると、専用URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行されます。
3. スマホのブラウザで開いて「ホーム画面に追加」すれば、ネイティブアプリ感覚で利用できます。
