# Synapse Research - 思考整理・研究ノート (v2.0)

> **トップダウン（大きな問い・仮説）とボトムアップ（先行研究・実験データ）を有機的に統合する思考整理ツール**

研究や論文執筆におけるアイデアの発想、先行研究の整理、実験データの検証、そして論理の構造化をスムーズに行うためのWebアプリケーションです。  
外部サーバー不要・完全無料で、ブラウザで開くだけですぐに利用できます。

---

## 🌟 新バージョン (v2.0) での主な進化・新機能

### 1. 矢印の生え際固定＆滑らかな曲線追従（スマートコネクタ）
- カードをつなぐ際、**引っ張り始めた丸（上・下・左・右）と相手の丸がしっかりと固定**されます。
- カードの位置を上下左右に動かしても、矢印の生え際が勝手にジャンプせず、位置関係に応じて**自然で美しいベジェ曲線（S字・U字カーブ）**を描いて追従します。
- 線の種類（実線／破線／矢印の向き／色など）も自由にカスタマイズ可能です。

### 2. AI研究サポート（Gemini連携）＋ 独自の追加指示機能
- 論文PDF、テキスト要約、音声ボイスメモ（mp3/m4a等）を投入すると、AIが「問い・仮説」や「知見・データ」のカードへ自動分解します。
- **「AIへの追加指示・着眼点」入力欄を新設**：
  - 「仮説検証の論理に注目して分解してほしい」
  - 「結論だけでなく実験手法のカードも作ってほしい」
  - 「簡潔に箇条書きでまとめてほしい」
  など、あなたの研究目的に合わせた特別な指示を添えてAIに解析させることができます。
- **カード事前確認モーダル**：AIが作成したカードをいきなりキャンバスに置くのではなく、事前に編集・取捨選択してから配置できます。

### 3. 4つの研究ジャンル（属性）に対応
思考の性質に合わせて4色のカラーとバッジでカードを分類できます：
- **問い・仮説**（Top-down / 青色）：研究の核となるリサーチクエスチョンや仮説
- **知見・メモ**（Bottom-up / 緑色）：先行研究の引用、サーベイメモ、観察結果
- **検証・合流**（Synthesis / 橙色）：実験結果、考察、仮説の支持・棄却の結論
- **その他・自由設定**（Custom / 桃色）：課題、TODO、アイデアなど自由に名前を設定可能

### 4. カードのコンパクト折りたたみ機能
- カードのバッジをクリックすると、**タイトルだけを残して小さく折りたたむ**ことができます。
- キャンバスがカードでいっぱいになっても、スッキリ整理して全体像を俯瞰できます。
- 折りたたみ状態のままでも横幅のリサイズが可能です。

### 5. マウス操作・キャンバス追従の完全精密化
- 拡大・縮小（ズーム）や背景スクロール（パン）を行っても、**マウスカーソルの位置ぴったりにカード移動や線つなぎが行える**ように改善されました。

### 6. プロジェクト管理・セーブ機能＆バックアップ
- **プロジェクト別セーブ**：「卒論_実験A」「輪講ノート」「サーベイ2026」など、名前をつけてキャンバスを保存・即座に切り替え可能。
- **JSON書き出し・読み込み**：カードや線の全データをワンクリックでファイルとして書き出し・バックアップ可能。

### 7. 利用規約および完全免責事項の完備
- システムやコードに関する知的財産権の帰属を明記。
- 現状有姿（AS-IS）の提供による完全免責条項を整備し、安全な運用が可能です。

## 🚀 使い方

### PCでの利用（一番かんたん）
1. フォルダ内の `index.html` をダブルクリックしてブラウザ（Google Chrome, Edge等）で開きます。
2. これだけでインストール作業なしですぐに使えます！

### スマートフォンや外出先からの利用（完全無料）
本アプリはHTML/CSS/JavaScriptのみで構成された静的Webサイトのため、無料でオンライン公開できます：
1. **GitHub Pages（おすすめ）**
   - GitHubのリポジトリに本フォルダのファイルをアップロードします。
   - リポジトリの **Settings ➡ Pages** を開き、「Branch: main / root」を選んで保存するだけで、スマホでアクセスできる専用URLが発行されます。
2. スマホのブラウザでそのURLを開き、「ホーム画面に追加」すれば専用アプリのように使えます。
