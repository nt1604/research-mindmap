【新バージョン (v3.1) の主な進化と新機能】

1. グループ機能＆一括収納・展開（スマートボックス）
   ・「+ グループ」ボタンからカード群をまとめる枠を作成。枠色の変更も可能。
   ・カード下の小さな丸「ドット（⚪ / 🔵 等）」を押すだけで所属を簡単切替。
   ・「📂 収納」でカードが箱の中に吸い込まれ、省スペースに整理。
   ・収納されたカードは「問い・仮説（青）」「知見・メモ（緑）」「検証（橙）」
     などジャンルごとの淡い色とバッジ付きで表示され、一目で把握できます。
   ・「📁 展開」で元の位置へワンクリックで復元。

2. 矢印の生え際固定＆滑らかな追従（スマートコネクタ）
   ・カードをつなぐ際、引っ張った丸（上下左右）の場所が固定されます。
   ・カードをどこへ動かしても矢印の生え際が勝手に跳ばず、
     位置関係に応じて滑らかで美しい曲線を描いて追従します。

3. AIサポート（Gemini連携）＋ 追加指示・着眼点機能
   ・論文PDF、テキスト、音声ボイスメモを自動でカード化します。
   ・「AIへの追加指示・着眼点」から目的別の抽出視点を指定可能。

4. 4つの研究ジャンル対応
   ・「問い・仮説（青）」「知見・メモ（緑）」「検証・合流（橙）」「その他（桃）」
   ・カードごとに色や属性を自由に切り替えられます。

5. 画面サイズ・レスポンシブ最適化
   ・ウィンドウを小さくしたりタブレットで開いても、
     ヘッダーのボタン群がはみ出さないように最適化されました。

6. プロジェクト別セーブ・管理機能（自動救済機能付き）
   ・「卒論_テーマA」「先行研究サーベイ」など、名前をつけて複数保存・切替可能。
   ・2段階スマート削除に対応（「削除」➡「本当に削除？」のタップで確実に抹消）。
   ・スマホ等で個別データが見当たらない場合でも、メイン保管庫から自動復元する救済機能を搭載。
   ・PCで「書き出し」したファイルをスマホで「読み込み」するだけで、端末間の完全データ移行が可能。
   ・「書き出し」ボタンでいつでもパソコンやUSBにバックアップできます。

7. 利用規約・完全免責事項の完備
   ・開発者の権利帰属と完全免責条項（AS-IS）を完備。

【Google連携・Gemini・GitHubアップロードについて】
Q. GitHubに上げさえすればいいの？
A. はい！このフォルダの内容をGitHubにアップロードするだけでOKです。
   ・AI機能（Gemini）：
     APIキーは個人のブラウザ内に安全に保存されるため、GitHubに公開しても
     キーが漏れる心配はありません。
   ・Google連携 / Firebase：
     現在はローカル保存とJSON書き出しで安全かつ完全に動作しています。

【PCでの起動方法（一番かんたんな方法）】
・このフォルダにある「index.html」をダブルクリックするか、
  ブラウザ（Google Chrome や Microsoft Edge 等）で開いてください。
・特別なソフトやインストール作業なしで、そのまま開いて使えます！

【GitHubへのアップロードとスマホからの利用】
・GitHubのリポジトリを作成し、このフォルダのファイルをアップロードしてください。
・リポジトリの「Settings ➡ Pages」をONにすると、
  スマートフォンから開ける専用URLが完全無料で発行されます。
