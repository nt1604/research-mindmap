このフォルダには、研究マインドマップアプリの全ファイル（HTML/CSS/JS）が
すべて揃って格納されています。

【1. PCでの起動方法（一番かんたんな方法）】
・このフォルダにある「index.html」をダブルクリックするか、
  Google Chrome や Microsoft Edge などのブラウザにドラッグ＆ドロップしてください。
・特別なソフトやインストール作業なしで、そのまま開いて使えます！
・中央大学の大学PCやご自宅のPCでも、OneDriveを同期していれば
  同じように index.html を開くだけですぐに作業できます。

【2. データのバックアップと移行】
・ブラウザ上部の「セーブ管理」ボタン：
  「卒論_実験A」「輪講ノート」など、テーマごとに名前をつけて何個でも保存できます。
・「書き出し」ボタン：
  カードや接続線のデータを「.json」ファイルとして保存・ダウンロードできます。
  USBメモリやメールで送る際や、別のPCで「読み込み」を押して開く時に便利です。

【3. スマートフォンや外出先（オンライン）から使う方法】
このアプリは外部サーバーを必要としない「静的Webサイト」なので、
完全無料でオンライン公開してスマホからURLで開くことができます。

おすすめの2つの方法：
① GitHub Pages（おすすめ・完全無料）
  GitHubのアカウントでリポジトリを作成し、この3つのファイルを
  アップロードして「Pages」を有効にするだけで、
  自分専用のWebサイトURL（https://username.github.io/xxx）が発行されます。
  スマホのブラウザでブックマークや「ホーム画面に追加」すれば、
  いつでもどこでもスマホから開けます。

② Vercel / Cloudflare Pages（数クリック・無料）
  GitHubと連携するか、フォルダをドラッグ＆ドロップするだけで
  数秒で独自URLが発行されます。

ご質問やオンライン公開の詳しい手順が必要な場合は、いつでもお声がけください！
