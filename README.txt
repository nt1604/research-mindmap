【新バージョン (v2.0) の主な進化と新機能】

1. 矢印の生え際固定＆滑らかな追従（スマートコネクタ）
   ・カードをつなぐ際、引っ張った丸（上下左右）の場所が固定されます。
   ・カードをどこへ動かしても矢印の生え際が勝手に跳ばず、
     位置関係に応じて滑らかで美しい曲線を描いて追従します。

2. AIサポート（Gemini連携）＋ 追加指示・着眼点機能
   ・論文PDF、テキスト、音声ボイスメモを自動でカード化します。
   ・「AIへの追加指示・着眼点」入力欄から、
     「仮説検証に注目してほしい」「手法も抽出してほしい」など、
     自由な視点を指定してAIに解析させることができます。

3. 4つの研究ジャンル対応
   ・「問い・仮説（青）」「知見・メモ（緑）」「検証・合流（橙）」「その他（桃）」
   ・カードごとに色や属性を自由に切り替えられます。

4. カードの折りたたみ機能
   ・カードのバッジをクリックするとタイトルだけ小さく折りたためます。
   ・キャンバスが広くなっても全体をスッキリ見渡せます。

5. マウス操作・描画精度の完全精密化
   ・画面を拡大・縮小・移動しても、マウスカーソルに吸い付くように
     正確にカード移動や線引きが行えます。

6. プロジェクト別セーブ・管理機能
   ・「卒論_テーマA」「先行研究サーベイ」など、名前をつけて複数保存・切替可能。
   ・「書き出し」ボタンでいつでもパソコンにバックアップできます。

7. 利用規約・完全免責事項の完備
   ・開発者の権利帰属と完全免責条項（AS-IS）を完備。

【PCでの起動方法（一番かんたんな方法）】
・このフォルダにある「index.html」をダブルクリックするか、
  ブラウザ（Google Chrome や Microsoft Edge 等）で開いてください。
・特別なソフトやインストール作業なしで、そのまま開いて使えます！

【GitHubへのアップロードとスマホからの利用】
・GitHubのリポジトリを作成し、このフォルダのファイルをアップロードしてください。
・リポジトリの「Settings ➡ Pages」をONにすると、
  スマートフォンから開ける専用URLが完全無料で発行されます。
